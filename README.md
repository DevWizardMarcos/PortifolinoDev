## 📦 How to Run Locally

### Clone the repository

```bash
git clone https://github.com/DevWizardMarcos/PortifolinoDev.git
```

### Access the project

```bash
cd PortifolinoDev
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
